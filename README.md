# BeatBench

BeatBench — офлайн-ориентированный eval-harness для проверки мультимодальных моделей на задаче создания карт Beat Saber. Модель получает аудио, обложку и метаданные, а затем должна вернуть валидный пакет карты V3.

Публичная версия содержит движок бенчмарка, схемы, пайплайн, автоматические диагностические метрики и рубрику человеческой оценки. Личные результаты прогонов, спектрограммы, CoT, треки, обложки и локальные инструменты загрузки на Quest намеренно не входят в репозиторий.

## Быстрый старт

Требования: Python 3.12+, [uv](https://docs.astral.sh/uv/) и `ffmpeg` в `PATH`.

```sh
uv sync
uv run beatbench evaluate track.mp3 \
  --endpoint https://api.example.com/v1 \
  --key "$BEATBENCH_API_KEY" \
  --model MODEL_NAME \
  --title "Track Title" \
  --author "Artist" \
  --bpm 174 \
  --nps 2.5 \
  -d ExpertPlus
```

Флаги `-d` / `--difficulty` можно указывать несколько раз. Для повторяемых запусков используйте sidecar `song.yaml` рядом с аудио; пример есть в `beatbench.example.toml` и документации.

## Что проверяет пайплайн

1. Модель создаёт `Info.dat` с окружением, цветами и освещением.
2. Для каждой сложности создаётся V3-файл с нотами, стенами, событиями, арками (`sliders`) и мультиблоками (`burstSliders`).
3. JSON Schema и структурные проверки отбраковывают невалидные карты.
4. Офлайн-проверка рассчитывает диагностические прокси для движения, музыкальности, развития паттернов, читаемости и презентации.
5. Карта упаковывается в ZIP только после прохождения гейта.

Автоматические значения 0–100 являются инженерными прокси и не заменяют игру человеком. Для абсолютной оценки используйте:

```sh
uv run beatbench judge-human results/<model>/<track>/<run>
uv run beatbench review-map results/<model>/<track>/<run>
```

Рубрика человеческой оценки использует пять осей: музыкальность, реакция на фразы, плотность и паузы, удобство игры, освещение и сцена.

## Ограничения

- Аудио длиннее 240 секунд обрезается в представлении для модели.
- В репозитории нет пользовательских треков, результатов вызовов API и секретов.
- Поддержка модов Beat Saber зависит от установленной версии игры и самих модов.
- Наличие событий освещения в JSON не доказывает качество их визуального исполнения; это проверяется в игре.
